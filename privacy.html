Privacy Policy

Last updated: 2 October 2026

This policy applies to "Hedge Fund Bot", a personal tool used only by its developer to access the developer's own Google account. Back to home.

Data accessed

With the owner's consent, the app uses the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly and reads only messages carrying the label "Trading" in the owner's own mailbox.

How it is used

The content of those messages is read to extract market information for the owner's private investment research. It is not used for advertising, profiling, or any purpose other than that.

Storage and sharing

An OAuth access token is stored on the owner's private server. Email content is processed on that server. Data obtained through Google APIs is not sold, shared with or transferred to third parties, and is not used to develop, improve or train generalized AI or machine-learning models.

Human access

No person other than the owner reads the data.

Retention and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions and delete the stored token from the server.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
